# 业务与产品逻辑

本目录用于集中记录项目的业务和产品设计，避免业务规则散落在代码、需求文档和口头沟通中。

后续可在此维护：

- 目标客户与使用角色
- 核心业务场景和端到端流程
- 业务对象、状态与关键规则
- 产品边界、能力范围和非目标
- 权限、审批、审计与异常处理要求
- 关键指标、验收标准和业务案例
- 重要产品决策及其原因
