# shenwei-agent-product · W1 起点（tag w1.0）

这是进入 W1 时仓库里有的全部东西：工程版需求三份文档，没有代码、没有规则、没有 CI。

- `docs/specs/product.md` 总 spec：范围与非目标、三个口径、用户故事与验收、质量指标
- `docs/requirements.md` 需求、非功能与成功标准：预算、证据、密钥各从哪周起
- `docs/threat-model.md` 威胁清单一页：密钥、工具权限边界、注入入口

W1 的九节在这上面逐步长出来：1.1 判定量表，1.2 周 spec 与任务书，1.3 ADR 与架构说明，1.4 收进仓库并补上 AGENTS.md、CI 与 CLI 骨架（tag w1.4），1.5–1.9 契约、模型与工具、Loop、预算与事件、新工具与发布（tag w1.5 … w1.9），完成版 tag w1。

tag 规则：`wN.0` 是第 N 周的起点，`wN.k` 是第 k 节结束时的状态，`wN` 是本周完成版。
