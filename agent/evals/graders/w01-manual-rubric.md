# W1 冒烟人工判定量表

每条冒烟记录：输入、工具轨迹（名称 + 参数 + 结果类别）、实际回答、运行配置（模型、max_steps、超时）、人工判定。

| 项 | 过 | 不过 |
|---|---|---|
| 事实来源 | 答复里的规格 / 交期数字能在工具结果里找到 | 出现工具结果里没有的数字 |
| 失败措辞 | 工具失败时说"无法确认"，不说"库存为零" | 把失败说成事实 |
| 缺信息 | 型号缺失时追问，不调 ERP | 猜型号或空调用 |
| 不必要调用 | 只问规格时可以不查库存；查了不算错但记录 | — |
| 语言 | 中文、简洁、不复述原始 JSON | 大段贴 JSON |
