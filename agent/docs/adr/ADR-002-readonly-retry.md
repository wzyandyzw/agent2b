# ADR-002 · 只读工具超时的有界重试，计入预算

日期 2026-10-24 · 状态 accepted · 关联 1.8 · 修订周 spec §5 开放问题

## 场景

1.6 时规格写"超时不重试"。1.8 注入库存超时后看到：一次瞬时超时就让整轮答复变成"交期无法确认"，而再查一次往往就有。

## 选择

只对错误类别为 `timeout` 的只读工具做有界重试，默认 0 次，CLI `--tool-retries` 可开；每次尝试都记 `tool.retry` 事件并计入步内耗时；`not_found` / `input_error` / `malformed` / `upstream_error` 不重试。

## 不做

W2 的写工具不能照搬这条：写操作的超时意味着结果未知，要用同一个幂等键重放，不是重试（见 `环境/接口通用规范.md` 第 2 节）。

## 证据

T11 三条：超时一次后成功计 2 次；一直超时在上限处停；404 不重试。
