# 需求、非功能与成功标准

业务需求见 `specs/product.md`（PRD 工程版）。本页只放周 spec 之外的横向要求。

| 类别 | 要求 | 从哪周起 |
|---|---|---|
| 预算 | 每个 Run 有步数、单次超时、墙钟上限；用量未知标 unknown 不当零 | W1 |
| 证据 | 每次模型请求快照与工具请求 / 执行 / 结果进事件文件；回放只读 | W1 |
| 密钥 | 只在 `.env`；不进代码、事件、日志、提交；CI 扫描 | W1 |
| 评测 | W1 人工判定六条冒烟；W4 判定器与案例集基线 | W1 / W4 |
| 观测 | W1 事件文件；W9 OTel Trace | W1 / W9 |
| CI | PR 跑单测 + 密钥扫描；W4 加 eval 回归 | W1 / W4 |
| 成功标准 | 见 `specs/product.md` §6 交付门槛 | — |
