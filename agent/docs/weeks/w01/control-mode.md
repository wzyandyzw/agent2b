# 控制方式对照（1.3）实录

固定流程 `scripts/fixed_flow.py`（不用模型）与 Loop（qwen-plus）跑同样的输入、同样的数据与错误处理。

## 固定流程输出

```
输入：查一下 X200 的规格和当前库存交期
固定流程：X200 离心输送泵：260 W；最大流量 5 L/min；最大压力 2 bar；IP54；挂牌价 2380.0 CNY。可用 5 台，最早 2026-09-23 深圳发运（观测 2026-09-20T10:00:00+08:00）。

输入：X200 的规格是什么
固定流程：X200 离心输送泵：260 W；最大流量 5 L/min；最大压力 2 bar；IP54；挂牌价 2380.0 CNY。可用 5 台，最早 2026-09-23 深圳发运（观测 2026-09-20T10:00:00+08:00）。

输入：上次那个型号现在有货吗
固定流程：请提供型号。

输入：查一下 X999 的规格
固定流程：型号 X999 不存在。
```

## Loop 输出（见 smoke-20261024.md 的 S01 / S02 / S03 / S04，以及 1.8 的继续会话实录）

| 输入 | 固定流程 | Loop |
|---|---|---|
| 查规格和交期 | 完全覆盖 | 覆盖，两个调用在一次响应里并行请求 |
| 只问规格 | 多查了一次库存（固定流程不看问法） | 只查规格 |
| 上次那个型号现在有货吗 | "请提供型号"（没有会话状态） | 继续会话时从历史取型号（S06） |
| X999 | 型号不存在 | 工具 not_found，模型说未找到 |
| 库存超时 | 固定文案 | 模型按错误类别措辞（S05） |

承认：主案例固定流程完全能做。选 Loop 的理由与代价在 ADR-001。
