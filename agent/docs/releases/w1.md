# Release w1 · 从需求到 Agent Loop

## 启动方式

```bash
git clone <repo> && cd shenwei-agent-product
cp .env.example .env                      # 填 DASHSCOPE_API_KEY
cd apps/agent-python && uv sync
uv run pytest tests/unit -q               # 离线，44 条里的 40 条；integration 需要 ERP
```

模拟 ERP：`S6/环境/shenwei-erp`，`uv run python -m shenwei_erp`（9100）。

## 必要配置

`.env`：`DASHSCOPE_API_KEY`（必填，真实模型）、`AGENT_MODEL`（默认 qwen-plus）、`ERP_BASE_URL`（默认 localhost:9100）、`ERP_API_KEY`（east-demo-key）、`AGENT_RUNS_DIR`（默认 runs，不入库）。

## 案例命令

```bash
uv run agent-cli chat "查一下 X200 的规格和当前库存交期"          # 主案例
uv run agent-cli chat --scripted "查一下 X200 的规格和当前库存交期"  # 离线
uv run agent-cli chat --resume <conversation_id> "那 X200-Pro 呢"    # 继续会话（新 Run）
uv run agent-cli chat --show-request "X200 的规格"                  # 看每步真正发给模型的 messages
uv run agent-cli chat --tool-retries 1 "查一下 T200 的规格和当前库存交期"
uv run agent-cli replay <conversation_id>                           # 只读回放
uv run python ../../scripts/smoke.py                                # 六条真实冒烟
uv run python ../../scripts/fixed_flow.py "X200 的规格是什么"        # 固定流程对照
uv run python ../../scripts/release_check.py
```

## 新增能力

CLI 对话；AgentLoop（最终文本 / 工具请求 / 协议失败三分支，串行执行、逐个配对）；三个 ERP 只读工具（查规格、查库存交期、查物流）；参数校验；ERP 错误分层；步数 / 墙钟预算；只读工具超时有界重试；JSONL 事件（请求快照无密钥）；只读回放；会话持久与继续（新 Run，未配对历史裁回完整边界）。

## 已知限制

不流式；工具串行；W1-AC-06 只有人工判定（W4 建判定器）；墙钟只在下一次调用前检查，不能中断阻塞中的调用；没有费用估算（W4）；继续会话不是恢复被杀的执行（W6）；百炼 qwen-plus 对 tool_call_id 错配不报错（见故障卡 3）。
