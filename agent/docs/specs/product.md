# 总 spec · 深维工作台「你的跨境数字员工」

这是 W0 PRD 的工程版。周 spec（`w01-*.md` …）只引用这里的条目，不改它的意思；发现这里有问题，写一条 ADR、改这里并升版本号。追溯链单向：总 spec 条目 → 周 spec → 测试 → tag。

## 1 范围与非目标

一个对话，一个 agent。业务员和它的 agent 对话；没有角色、没有员工团队，所有能力都在工具层和技能层，按插件安装。每条请求起一个 Run，agent 在循环里选工具、调用、观察、继续，直到停止。

本期不做：面向终端客户的客服机器人（agent 不直接和客户对话）；审批流（写动作由使用者自己确认，没有主管审批）；真接企业系统（ERP、SCRM 本地模拟）；多个 agent 角色；移动端；前端开发（成品）。

## 2 三个口径

| 口径 | 内容 |
|---|---|
| 读自由、写过闸 | 只读工具自动执行；写动作先以变更集出现在对话里，业务员确认才发生。询问模式下所有写动作等确认；自动模式下内部写不问、对外写仍问。没有审批。 |
| SCRM 只有四个对象 | 客户与联系人、归档会话记录、跟进记录、线索分级。没有询盘对象；agent 不替业务员回客户，只整理答复要点。 |
| 价格只由 ERP 算 | 报价工具没有自由金额参数；价格按报价规程由 ERP 计算。 |

三条不变式，从第一周起成立：
- I1 模型看到的每一条上下文都已记录在事件日志里，任取一步都能复原当时发给模型的完整请求。
- I2 工具调用先落日志再执行，被拒绝的、等确认的也要记。
- I3 价格由报价规程计算，报价工具没有自由金额参数。

## 3 五层与八个插件

层：对话与运行时 / 工具层 / 技能层 / 知识层 / 平台层。
插件：ERP 连接器（查规格、查库存交期、查订单、查物流、查客户与回款、写报价台账、建售后工单）、SCRM 连接器、设备选型与报价、客户背调、文档与表格、设计、飞书（只发不收）、采购寻源（选修）。

权限档位默认：只读工具自动；沙箱计算与生成文件自动；内部写（跟进、工单、线索分级、定时任务、飞书提醒）自动但询问模式下也问；对外写（归档答复要点、发送报价单并写台账、合同草稿、归档营销图）询问；跨工作空间访问禁止（404）。

## 6 质量指标（7 个，案例集上算，分子分母都给）

终态正确率、动作正确率、错误动作率、重复副作用数（必须为 0）、诉求覆盖率、引用正确率、每个成功任务成本。
交付门槛：24 条 AC 全过；重复副作用 0；错误动作率 ≤ 2%；每个成功任务成本 ≤ 0.5 元（背调 ≤ 2 元）。

## 7 终态与 Run 状态

终态：`resolved / needs_clarification / declined / failed / partially_resolved`；Run 可处于 `waiting_for_user`（W6 起）。
W1 只实现 Run 的最小执行状态（running / completed / failed / stopped）；completed 只表示循环得到有效结束响应，不证明业务内容正确。
