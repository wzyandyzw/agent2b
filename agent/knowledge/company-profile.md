# 汇甬新材公司概况

浙江汇甬新材料有限公司专注分子筛膜材料及膜分离系统产业化，业务覆盖材料研发、膜组件制造、工业系统集成和工程交付。

公司产品应用于燃料乙醇、医药、精细化工、煤化工、锂电池材料等场景。公开案例涉及乙醇、异丙醇、NMP、四氢呋喃和二氯甲烷等有机溶剂的脱水、精制或回收。

公司面向工业客户提供按工况定制的产品和成套装置。项目通常需要确认介质、组成、处理量、含水率、目标纯度、温度、压力和现场公用工程条件。
