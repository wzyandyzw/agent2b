# 汇甬全公司数字员工 CLI Demo PRD

> 版本：0.1  
> 状态：第一阶段已交付，待客户访谈验证

## 1. 产品背景

汇甬的业务横跨销售、技术方案、报价、项目交付、采购、财务和售后。业务人员需要在 ERP、客户资料、产品资料、案例和历史文件中来回查询，再手工整理方案、报价和跟进信息。

第一阶段不开发完整企业平台，而是用 CLI 验证一个通用 Agent 是否能连接多个业务工具，完成不同部门的任务。

## 2. 产品目标

让员工用一句自然语言提出任务，Agent 能够：

1. 理解任务并决定需要查询哪些系统；
2. 组合多个工具，取得真实业务事实；
3. 检索企业知识并说明来源；
4. 生成可执行的摘要、方案或报告；
5. 在信息不足或工具失败时明确说明；
6. 保留完整执行记录，支持会话续跑和回放。

## 3. 目标用户

- 销售和售前：客户跟进、产品选型、报价准备。
- 项目与交付：订单、库存、物流和交付异常。
- 财务：应收、逾期和回款风险。
- 管理层：跨系统经营摘要。
- 其他岗位：知识查询、文档和重复信息整理。

## 4. 第一阶段范围

### 必须包含

- CLI 单 Agent 对话。
- ERP 产品、库存、订单、物流、客户和应收查询。
- 产品选型和规则化报价计算。
- 企业知识检索及来源引用。
- Markdown 报告输出。
- 超时、错误、参数校验和预算控制。
- 事件记录、会话续跑与回放。
- 无模型密钥可运行的离线 Demo。

### 不包含

- Web、移动端和管理后台。
- 多 Agent 自主协作。
- 真实 CRM、OA、飞书和客户系统接入。
- 生产系统写入、合同发送和对外消息发送。
- 多租户、计费和正式审批体系。

## 5. 核心场景

| 编号 | 场景 | 成功结果 |
|---|---|---|
| PRD-01 | 汇总客户订单、物流和回款 | 跨系统事实一致，指出异常和下一步 |
| PRD-02 | 判断订单物流是否延误 | 返回承诺时间、最新轨迹和签收状态 |
| PRD-03 | 检查客户应收风险 | 返回余额、逾期天数、信用状态 |
| PRD-04 | 根据工况完成选型和报价 | 候选产品合理，价格由 ERP 规则计算 |
| PRD-05 | 生成经营异常摘要 | 输出关键订单、风险和可执行建议 |
| PRD-06 | 检索产品与业务知识 | 返回相关原文片段及来源 |
| PRD-07 | 查询产品规格和库存交期 | 返回产品参数、可用量、交期和观察时间 |

## 6. 成功标准

- 7 个核心场景均可通过一条 CLI 命令完成。
- 业务事实来自工具或知识库，不依赖模型记忆。
- 工具失败不会被包装成正常业务结果。
- 报价金额只能来自报价规则。
- 每次执行都能回放模型请求和工具调用。
- 第一阶段 Demo 可以由新环境一键启动。

## 7. 风险与假设

- 当前使用模拟 ERP 和本地知识库，真实接口尚未确认。
- 离线模式使用确定性规划器，只验证产品链路，不代表最终自然语言能力。
- 真实模型效果需配置模型密钥并在扩展案例集上评测。
- 客户数据和系统权限边界尚未经过汇甬现场验证。
